# Arbitrages de règles V11

Ce registre complète uniquement une règle officielle dont le texte disponible
est réellement incomplet ou indéterminé. Il ne remplace pas une source absente
et ne sert pas à simplifier une règle difficile à implémenter.

Chaque arbitrage doit contenir :

- un identifiant stable `ARB-NNN` ;
- les identifiants et versions des sources officielles concernées ;
- le passage incomplet et les comportements encore possibles ;
- la décision exacte approuvée par le propriétaire, sa date et son périmètre ;
- les commandes, événements, tests et versions de sauvegarde affectés ;
- un statut `draft`, `approved`, `superseded` ou `withdrawn`.

Une entrée `draft` n'est jamais exécutable. Une nouvelle FAQ ou errata officiel
supplante l'arbitrage après revue et migration explicites.
