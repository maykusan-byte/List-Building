# ADR-004 — Couverture explicite des règles

- Statut : accepté
- Date : 2026-08-13

## Décision

Les règles, profils physiques et scénarios sont versionnés avec leur source. Le moteur n'interprète pas de texte naturel ; il refuse une action ou partie dont la couverture est incomplète.

## Conséquences

Les conventions non officielles sont signalées, versionnées et soumises à revue humaine.
