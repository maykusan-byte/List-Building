# Archive Warorgan

Cette archive conserve les deux applications HTML antérieures et
`master_warorgan.json`. Elles ne font pas partie de Warforge et ne sont pas
publiées.

La base JSON reste disponible pour les scripts de migration d’inventaire de
Warforge. Ne la modifier, ni n’exécuter les anciennes pages, sans une demande
explicite ; les identifiants et exports historiques peuvent être ambigus.
